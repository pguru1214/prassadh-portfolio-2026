# Guru Prasad — Product Designer & UI Engineer

A mobile-first portfolio built with React, TypeScript and Tailwind CSS. The experience presents Guru Prasad as a hybrid product designer and UI engineer, with a 35% UX / 65% UI emphasis.

## Portfolio sections

- Intro and role positioning
- About, strengths and current experience at ValueLabs
- Selected product work across AI, EdTech and FinTech
- Product design process
- Design and engineering toolkit
- Contact

## Run locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Deploy to Netlify

1. Upload this project to GitHub, GitLab or Bitbucket.
2. In Netlify, choose **Add new site → Import an existing project**.
3. Select the repository. Netlify will read `netlify.toml`.
4. Deploy.

The project uses Node.js 22. The contact section is configured for `prassadh1994@gmail.com`.
